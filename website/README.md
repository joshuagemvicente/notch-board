# NotchBoard website

Marketing site for [NotchBoard](https://github.com/joshuagemvicente/NotchBoard) — Next.js, Tailwind, shadcn/ui, Manrope.

## Develop

```bash
cd website
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

Download links point at GitHub Releases. Edit `src/lib/site.ts` if the repo URL changes.
